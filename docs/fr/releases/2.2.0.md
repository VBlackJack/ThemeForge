# ThemeForge 2.2.0

[English](../../releases/2.2.0.md)

Créez une palette dans Studio, enregistrez-la en JSON et réutilisez-la dans une autre
application WPF sans recompiler le moteur. Cette version renforce aussi la validation
des saisies, la mémorisation des préférences, l’accessibilité et les contrôles de publication.

## Télécharger et démarrer

- **Studio :** extrayez `ThemeForge.Studio-2.2.0-win-x64.zip`, puis lancez
  `ThemeForge.Studio.exe` sous Windows x64. Le runtime .NET est inclus, sans installation.
- **Nouvelle application :** `dotnet new install ThemeForge.Templates::2.2.0`, puis
  `dotnet new tf-wpf -n MyApp`.
- **Application existante :** passez ensemble ThemeForge.Theme, ThemeForge.Controls et
  ThemeForge.Theme.DependencyInjection en 2.2.0.
- Quatre fichiers `.nupkg` et `SHA256SUMS.txt` accompagnent la release.

## Nouveautés

- Palettes JSON versionnées : 25 couleurs opaques, attribution obligatoire,
  validation stricte et enregistrement atomique. Chargement via le catalogue optionnel
  ou `ThemeForgeOptions.Palettes`.
- Studio : ouvrir, enregistrer, exporter, annuler/rétablir, protéger les modifications,
  comparer avant/après, vérifier les couleurs et diagnostiquer le contraste du texte.
- Journal quotidien asynchrone configurable.
- Test d’application générée isolée : lecture d’un export Studio puis restauration
  de la palette et de l’accent après redémarrage.
- Matrice visuelle/UIA et budgets de performance reproductibles intégrés à la CI.

## Corrections

- Les saisies numériques non finies et dépassements n’altèrent plus les valeurs.
- Les accents invalides sont rejetés avant modification du thème actif.
- Les modifications de palette sont isolées ; les changements de thème protègent le brouillon.
- Le suivi Windows est mémorisé même sans changement visuel ; désactiver le suivi
  d’accent arrête une souscription existante.
- Contraste des boutons, nom accessible et focus de fermeture des notifications,
  redimensionnement DataGrid et respect de la réduction des animations.
- NOTICE et licences inclus dans les packages ; contrôles communs sur les tags et
  arrêt sur les échecs de publication.

## Migration et validation

`IThemeService` reste compatible. Les palettes externes utilisent des capacités optionnelles.
Enregistrez-les avant de restaurer les préférences. Voir le
[guide des palettes](../external-palettes.md) pour le contrat JSON et l’initialisation.

Avant publication : 261 tests réussis, couverture du moteur à 83,27 % des lignes,
parcours consommateur et budgets de performance validés, 36 captures produites.
Le clavier physique, les annonces Narrator et les changements réels de DPI restent
à vérifier avec la [recette manuelle](../quality.md).
