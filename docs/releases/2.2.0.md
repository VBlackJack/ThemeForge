# ThemeForge 2.2.0

[Français](../fr/releases/2.2.0.md)

Create a palette in Studio, save it as JSON and load it in another WPF application
without rebuilding the theme engine. This release also improves input validation,
preference persistence, control accessibility and publication checks.

## Download and start

- **Studio:** extract `ThemeForge.Studio-2.2.0-win-x64.zip` and launch
  `ThemeForge.Studio.exe` on Windows x64. The .NET runtime is included; no installer is required.
- **New applications:** `dotnet new install ThemeForge.Templates::2.2.0`, then
  `dotnet new tf-wpf -n MyApp`.
- **Existing applications:** update ThemeForge.Theme, ThemeForge.Controls and
  ThemeForge.Theme.DependencyInjection together to 2.2.0.
- The release includes four `.nupkg` files and `SHA256SUMS.txt` for download verification.

## Added

- Versioned JSON palettes with 25 opaque colour slots, required attribution,
  strict validation and atomic saves. Register external palettes through the optional
  catalogue capability or `ThemeForgeOptions.Palettes`.
- Studio open/save/export, undo/redo, unsaved-change protection, original/edited
  preview, immediate colour validation and text contrast diagnostics.
- Configurable asynchronous daily Studio logging.
- Isolated generated-application tests that consume a Studio export and restore
  palette/accent preferences after restart.
- Visual/UIA matrix and repeatable performance budgets shared with CI.

## Fixed

- Non-finite numeric input and stepping overflow no longer corrupt control values.
- Invalid accents are rejected before active theme state changes.
- Palette edits stay isolated; deliberate theme changes protect unsaved documents.
- Windows-follow intent is persisted even without a visible palette change;
  disabling accent following stops an existing subscription.
- Button text adapts to accent contrast, toast close buttons have an accessible name
  and keyboard focus, DataGrid resizing works, and reduced-motion settings are respected.
- Packages include NOTICE and license texts. Tagged builds run the same verification
  chain and stop on publication failures.

## Upgrade and validation

`IThemeService` remains compatible. External palettes use separate optional capabilities.
Register external palettes before restoring saved preferences. See the
[palette guide](../external-palettes.md) for the JSON contract and bootstrap example.

Validation before release: 261 tests pass; engine line coverage is 83.27%. The isolated
consumer round trip and performance budgets pass. The visual matrix produces 36 captures.
These checks do not certify physical keyboard traversal, Narrator announcements or
native monitor DPI changes; follow the [manual acceptance recipe](../quality.md).
